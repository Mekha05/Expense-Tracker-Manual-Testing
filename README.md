# Expense Tracker Web Application — Manual Testing

## Project Overview
This mini project focuses on manually testing the core functionality of an Expense Tracker web application, including transaction entry, amount validation, and transaction data handling.

## Testing Objectives
- Verify that the application loads correctly.
- Validate transaction input fields.
- Check numeric input handling for transaction amounts.
- Verify data persistence after refreshing the page.
- Identify invalid input handling issues.
- Document test execution results and defects.
